# Skill: security-review

## فرمان
`/security-review`

## هدف
بررسی ساختاریافته امنیت پروژه با تمرکز بر احراز هویت، مجوزها، داده، ورودی‌ها، Secrets، وابستگی‌ها و استقرار.

## دستورالعمل
1. دارایی‌ها، داده‌های حساس، نقش‌ها و مرزهای اعتماد را مشخص کن.
2. Authentication، Authorization و مدیریت Session را بررسی کن.
3. ورودی‌ها، Upload، APIها، Webhookها و Injection را ارزیابی کن.
4. نگهداری Secrets، Encryption، Logging و Privacy را بررسی کن.
5. وابستگی‌ها، CI/CD، Docker و تنظیمات Production را ارزیابی کن.
6. یافته‌ها را بر اساس شدت، احتمال و قابلیت بهره‌برداری اولویت‌بندی کن.
7. برای هر یافته، راه‌حل کوتاه‌مدت و اصلاح پایدار پیشنهاد بده.

## قالب خروجی
- Threat Model خلاصه
- یافته‌های Critical/High/Medium/Low
- شواهد
- پیامد
- اصلاح پیشنهادی
- تست امنیتی لازم
