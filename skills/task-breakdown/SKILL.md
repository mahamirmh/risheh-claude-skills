# Skill: task-breakdown

## فرمان
`/task-breakdown`

## هدف
تبدیل یک پروژه یا قابلیت بزرگ به تسک‌های کوچک، قابل واگذاری و دارای معیار پایان.

## دستورالعمل
1. هدف، Scope و وابستگی‌ها را استخراج کن.
2. پروژه را به فاز، Epic، Task و Subtask تقسیم کن.
3. برای هر تسک، خروجی، مسئول پیشنهادی، پیش‌نیاز و معیار پذیرش بنویس.
4. وابستگی‌ها و مسیر بحرانی را مشخص کن.
5. تسک‌های مبهم را به تحقیق یا تصمیم جداگانه تبدیل کن.
6. از تخمین ساختگی خودداری کن؛ در صورت نبود داده، بازه و فرض را بنویس.

## قالب خروجی
- فازها
- تسک‌ها و Subtaskها
- وابستگی‌ها
- معیار پذیرش
- اولویت
- ریسک‌ها
- تعریف Done
