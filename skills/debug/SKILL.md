# Skill: debug

## فرمان
`/debug`

## هدف
عیب‌یابی ساختاریافته بر اساس شواهد، بازتولید خطا و حذف حدس‌های بی‌پایه.

## دستورالعمل
1. خطا، محیط، نسخه‌ها و رفتار مورد انتظار را ثبت کن.
2. مراحل بازتولید حداقلی بساز.
3. لاگ، Stack Trace و تغییرات اخیر را تحلیل کن.
4. فرضیه‌ها را بر اساس احتمال و هزینه بررسی اولویت‌بندی کن.
5. هر بار فقط یک متغیر را تغییر بده.
6. راه‌حل موقت را از Root Cause Fix جدا کن.
7. بعد از اصلاح، Regression Test و روش جلوگیری از تکرار را مشخص کن.

## قالب خروجی
- شرح مسئله
- شواهد
- فرضیه‌ها
- آزمایش‌ها
- علت اصلی
- اصلاح پیشنهادی
- تست تأیید
- پیشگیری
