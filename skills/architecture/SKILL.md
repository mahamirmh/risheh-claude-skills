# Skill: architecture

## فرمان
`/architecture`

## هدف
طراحی معماری نرم‌افزار قابل توسعه، امن، قابل نگهداری و متناسب با محدودیت‌های واقعی پروژه.

## دستورالعمل
1. نیازمندی‌ها، بار، نقش‌ها، داده‌ها و محدودیت‌ها را استخراج کن.
2. معماری منطقی، اجزا، مرز مسئولیت و جریان داده را تعریف کن.
3. گزینه‌های جایگزین و Trade-offها را مقایسه کن.
4. مدل استقرار، امنیت، Observability، Backup و Disaster Recovery را پوشش بده.
5. از پیچیدگی زودهنگام جلوگیری کن و مسیر رشد مرحله‌ای پیشنهاد بده.
6. تصمیم‌ها و فرضیات را در قالب ADR ثبت کن.

## قالب خروجی
- Context
- Requirements
- Proposed Architecture
- Components and Responsibilities
- Data Flow
- Security
- Deployment
- Observability
- Scalability
- Trade-offs
- ADRs
- Risks and Next Steps
