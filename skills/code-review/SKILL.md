# Skill: code-review

## فرمان
`/code-review`

## هدف
بازبینی کد از نظر صحت، امنیت، نگهداشت‌پذیری، عملکرد و تطابق با معماری پروژه.

## دستورالعمل
1. ابتدا Scope تغییرات و هدف کد را مشخص کن.
2. ایرادهای قطعی را از پیشنهادهای سلیقه‌ای جدا کن.
3. منطق، Edge Caseها، مدیریت خطا، امنیت و Race Condition را بررسی کن.
4. اثر تغییر روی API، دیتابیس، سازگاری عقب‌رو و Performance را تحلیل کن.
5. مسیر فایل و محل مسئله را دقیق ذکر کن.
6. برای هر ایراد، شدت، دلیل، پیامد و راه‌حل پیشنهاد بده.
7. در نبود شواهد، ادعای وجود باگ نکن.

## قالب خروجی
- خلاصه تغییرات
- Findings بحرانی
- Findings مهم
- پیشنهادهای بهبود
- تست‌های لازم
- نتیجه نهایی
