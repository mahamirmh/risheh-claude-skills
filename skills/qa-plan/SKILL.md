# Skill: qa-plan

## فرمان
`/qa-plan`

## هدف
ساخت برنامه تست قابل اجرا برای بررسی کیفیت، صحت و آمادگی انتشار یک قابلیت یا محصول.

## دستورالعمل
1. Scope، نقش‌های کاربری و مسیرهای اصلی را مشخص کن.
2. سناریوهای مثبت، منفی، Edge Case و Regression را طراحی کن.
3. تست‌های Unit، Integration، E2E، Security، Performance و Accessibility را تفکیک کن.
4. برای هر سناریو، پیش‌شرط، مراحل، داده تست و نتیجه مورد انتظار بنویس.
5. اولویت و شدت خرابی را تعریف کن.
6. معیار ورود، خروج و پذیرش تست را مشخص کن.

## قالب خروجی
- Test Scope
- Environments
- Test Matrix
- Test Cases
- Test Data
- Entry/Exit Criteria
- Risks
- Release Recommendation
