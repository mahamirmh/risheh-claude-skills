# Skill: write-a-skill

## فرمان
`/write-a-skill`

## هدف
ساخت یک Skill جدید، کوچک، روشن و قابل نگهداری برای Claude Code یا Claude Cowork.

## دستورالعمل
1. مسئله‌ای را که Skill باید حل کند دقیق تعریف کن.
2. فرمان کوتاه و یکتا انتخاب کن.
3. ورودی‌ها، رفتار مورد انتظار و محدودیت‌ها را مشخص کن.
4. دستورالعمل‌ها را به مراحل روشن و بدون ابهام تبدیل کن.
5. قالب خروجی ثابت و مثال استفاده اضافه کن.
6. موارد ایمنی، محرمانگی و نیاز به بازبینی انسانی را ذکر کن.
7. از ساخت Skillهای بسیار گسترده و چندمنظوره خودداری کن.
