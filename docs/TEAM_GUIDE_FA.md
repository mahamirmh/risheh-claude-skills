# راهنمای استفاده تیم ریشه از Claude Skills

## Skill چیست؟
Skill یک دستورالعمل استاندارد و قابل استفاده مجدد است که به Claude می‌گوید یک نوع کار مشخص را با چه مراحل، محدودیت‌ها و قالب خروجی انجام دهد.

## نصب پیشنهادی

- برای استفاده شخصی روی چند پروژه: نصب سراسری در `~/.claude/skills`
- برای پروژه حساس یا دارای قواعد اختصاصی: نصب Project-local در `<project>/.claude/skills`

Skill پروژه‌ای می‌تواند برای همان Repository سفارشی شود و همراه کد Version Control شود؛ اما قبل از Commit مطمئن شوید هیچ اطلاعات حساس داخل فایل‌ها نیست.

## جریان کار پیشنهادی

1. مسئله را با `/grill-me` نقد و اعتبارسنجی کنید.
2. نیازمندی را با `/prd` یا `/task-breakdown` ساختاربندی کنید.
3. برای اجرای کار از `/prompt-master` استفاده کنید.
4. هنگام توسعه، `/architecture`، `/debug` و `/code-review` را اجرا کنید.
5. قبل از انتشار، `/qa-plan`، `/security-review` و `/release-checklist` را اجرا کنید.
6. برای تحویل کار از `/handoff` استفاده کنید.

## نمونه‌ها

```text
/prd برای پلتفرم مدیریت مدرسه با نقش‌های مدیر، معلم، دانش‌آموز و والدین PRD بنویس
```

```text
/task-breakdown این PRD را به فاز، Epic، Task و معیار پذیرش تبدیل کن
```

```text
/security-review احراز هویت و سطح دسترسی این پروژه FastAPI را بررسی کن
```

## قواعد تیمی

- خروجی AI بدون بازبینی انسانی نهایی نیست.
- Password، Token، API Key و اطلاعات مشتری را داخل درخواست قرار ندهید.
- برای تغییرات destructive ابتدا Backup و Rollback Plan داشته باشید.
- فرض‌های مدل را از واقعیت‌های پروژه جدا نگه دارید.
- تصمیم مهم معماری باید در ADR یا مستند پروژه ثبت شود.
- هر Skill باید یک مسئولیت روشن داشته باشد؛ Skillهای بیش‌ازحد گسترده نگهداری دشواری دارند.

## عیب‌یابی نصب

### Skillها نمایش داده نمی‌شوند

1. مسیر نصب را بررسی کنید.
2. Claude Code را کاملاً ببندید و دوباره باز کنید.
3. مطمئن شوید هر Skill در یک پوشه مستقل و دارای فایل `SKILL.md` است.
4. نام پوشه و فرمان را کوتاه، یکتا و بدون فاصله نگه دارید.

### PowerShell اجرای اسکریپت را مسدود می‌کند

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

### در macOS مجوز اجرا وجود ندارد

```bash
chmod +x scripts/install-macos.sh scripts/install-local.sh
```

## به‌روزرسانی

```bash
git pull
```

سپس اسکریپت نصب مناسب سیستم‌عامل را دوباره اجرا کنید تا فایل‌ها به‌روزرسانی شوند.
